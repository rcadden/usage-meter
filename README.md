# usage-meter

A Claude mod that shows your 5-hour and 7-day usage limits (percent used and time left) in a band above the prompt.

## Install

From a shell:

```bash
claude plugin marketplace add rcadden/usage-meter
claude plugin install usage-meter@ricky-mods --scope user
```

Or at the prompt of a terminal session:

```
/plugin install usage-meter --marketplace rcadden/usage-meter
```

In the desktop app: click + next to the prompt box, then Plugins, Add marketplace with `rcadden/usage-meter`, then Add plugin.

## Update

```bash
claude plugin marketplace update ricky-mods
claude plugin update usage-meter@ricky-mods
```
